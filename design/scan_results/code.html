Finding Details

SMBv1 protocol detected as enabled on port 445. This protocol is highly vulnerable to remote code execution attacks, notably the EternalBlue exploit used by WannaCry and NotPetya ransomware.

CVE-2017-0144
Remote Code Execution Vulnerability in Microsoft SMBv1 Server

Remediation Recommendation

  • Immediately disable SMBv1 across the network.
  • Apply MS17-010 security update if legacy systems mandate SMBv1 (not recommended).
  • Restrict access to port 445 via network firewalls to internal trusted IP ranges only.
  • Upgrade to SMBv2 or SMBv3.
